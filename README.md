#### 🔹 Full‑stack QA — Кошелек.ру (2025 — сейчас)

Разрабатываю и поддерживаю фреймворки автотестов, интегрирую тесты в CI и помогаю ускорять релизы.

**Что делаю:**
- E2E‑тестирование **веб** и **мобильного** приложения:
  - функциональное, регрессионное, интеграционное тестирование
  - тестирование **API** (Postman, Swagger, REST, WebSockets)
  - тестирование **UI** (DevTools, Charles), проверка UX/UI
  - анализ логов (**Kibana**) и трассировок (**Jaeger**)
- Работаю с **WebSockets**: проверяю корректность и стабильность соединений, обработку событий в реальном времени
- Автоматизирую тестирование:
  - **Playwright + Pytest** — UI‑автотесты для веб
  - **Appium + Pytest** — автотесты для Android (POM)
  - **API** — автотесты с библиотекой requests и Asyncio
  - **Gherkin** — формализация сценариев
- Автоматизирую процессы вокруг тестирования:
  - **Bash‑скрипты** для подготовки окружения, прогонов и сбора артефактов
  - работа в **Ubuntu**, GitHub / GitLab CI

**Достижения:**
- 🔸 Перевёл **100% тест‑кейсов на Gherkin**, сократив время на понимание сценариев командой примерно на **40%**
- 🔸 Спроектировал и внедрил **Appium + Pytest (POM)**‑фреймворк, покрыл критические E2E‑сценарии, за счёт чего:
  - ускорились регресс‑прогоны
  - повысилась стабильность релизов
- 🔸 Выявлял критические UX/UI‑дефекты до релиза и предотвращал их попадание в прод
